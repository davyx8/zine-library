# zine-library

A little library of hand-drawn tech zines: ffmpeg, gstreamer, sed, and awk.

Published with GitHub Pages: https://davyx8.github.io/zine-library/

## Structure

- `index.html` — the library, one card per zine
- `zines/*.html` — one page per zine, full-size pages
- `img/thumbs/` — small cover thumbnails for the library grid
- `img/full/` — full-size zine pages
- `style.css` — the blue

No build step. Just static HTML/CSS.
