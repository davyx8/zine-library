find: Search Like a Detective

Hunt down files by name, type, size, and age — then act on what you find with -exec and xargs.

find

search the filesystem like a detective

one command, infinite haystacks

1 Basic syntax

find  

find . -name "*.txt"
  • path defaults to . if you leave it out
  • expression = tests (what to match) + actions (what to do)
  • walks the whole tree under path, recursively, by default

2 Find by name

find . -name "*.log"
find . -iname "readme*"
  • -name is case-sensitive
  • -iname ignores case
  • quote your patterns so the shell doesn't expand * first

3 Find by type

find . -type f   # regular files
find . -type d   # directories
find . -type l   # symlinks
  • f = file, d = directory, l = symlink
  • combine with -name: find . -type f -name "*.py"

4 Find by size or age

find . -size +10M
find . -mtime -7
find . -newer ref.txt
  • +10M — bigger than 10MB (-10M = smaller than)
  • -mtime -7 — modified less than 7 days ago
  • -newer — modified more recently than ref.txt

5 Act on what you find

find . -name "*.tmp" -delete
find . -name "*.log" -exec gzip {} \;
find . -name "*.bak" -exec rm {} +
  • {} is swapped for each matched path
  • \; runs the command once per file — + batches many files into fewer calls
-delete and -exec rm are permanent. Run with -print first to see what would match.

6 Combine with xargs

find . -name "*.log" | xargs rm
find . -name "*.png" -print0 | xargs -0 du -h
  • -print0 + xargs -0 handles filenames with spaces safely
