jtop: htop for Your Jetson

CPU, GPU, RAM, temps, and power modes in one live dashboard — plus how to log it all to a file.

jtop

htop for your Jetson

Jetson edition

1 Install

sudo pip3 install -U jetson-stats
sudo reboot
  • jtop ships in the jetson-stats package
  • a reboot is required the first time so the service can register

2 Launch it

jtop
  • opens a live full-screen dashboard, same instinct as htop
  • may need sudo the first time, depending on socket permissions

3 Read the tabs

  • ALL — CPU, GPU, RAM, temps and power together
  • CPU / GPU / MEM — per-engine load and frequency
  • CTRL — fan, power mode, jetson_clocks toggles
  • flip through tabs with the arrow keys

4 Power modes

sudo nvpmodel -q
sudo nvpmodel -m 0
sudo jetson_clocks
  • -q shows the current power mode
  • -m N switches modes (0 is usually max performance)
  • jetson_clocks locks clocks at their max for benchmarking

5 Log stats instead of watching them

from jtop import jtop

with jtop() as jetson:
    while jetson.ok():
        print(jetson.stats)
  • jetson.stats is a dict: CPU/GPU load, RAM, temps, power
  • write each iteration to a CSV row for a lightweight logger
  • the same jtop package the interactive dashboard is built on

6 Handy keys inside jtop

  • q — quit
  • arrows / numbers — switch tabs
  • c — clear a fan/power alarm
