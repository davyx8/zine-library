mediainfo: The Librarian for Your Media

Every stream, codec, and container detail — in plain text, JSON, or exactly the one field you asked for.

mediainfo

the librarian for your media files

every stream, every detail

1 Basic usage

mediainfo file.mp4
  • prints a readable report: general info, then one section per stream
  • works on video, audio, image, and subtitle files alike

2 Machine-readable output

mediainfo --Output=JSON file.mp4
mediainfo --Output=XML file.mp4
  • JSON is the easiest to pipe into jq or a script
  • both formats expose every field the text report summarizes

3 Ask for one exact field

mediainfo --Inform="Video;%Width%x%Height%" file.mp4
mediainfo --Inform="General;%Duration/String%" file.mp4
  • --Inform takes a template; %FieldName% gets swapped in
  • great for scripts that only need a single number, not a whole report

4 Compare to ffprobe

  • mediainfo tends to surface more container/encoder metadata by default
  • ffprobe is faster for raw stream stats and pairs with the rest of ffmpeg
  • use whichever one is already in your pipeline

5 Batch a whole folder

mediainfo --Output=JSON *.mp4 > report.json

find . -name "*.mkv" \
  -exec mediainfo --Inform="Video;%Format%" {} \;
  • mediainfo accepts multiple files directly, one report each
  • combine with find for a recursive scan of a whole tree

6 Fields worth knowing

  • %CodecID% %Format% %Width% %Height% %FrameRate%
  • %Duration/String% %OverallBitRate% %AudioCount%
  • run mediainfo --Info-Parameters for the full list
Try it now!
Run mediainfo --Inform="Video;%Format% %Width%x%Height% @ %FrameRate%fps" file.mp4 for a one-line summary.
