tree: See the Shape of a Directory

Depth limits, hidden files, sizes, and filters — one command to stop guessing what's in a folder.

tree

see the shape of a directory at a glance

no more cd && ls, cd && ls

1 Basic usage

tree
tree /path/to/dir
  • draws the directory as a branching diagram
  • run with no arguments to tree the current folder

2 Limit the depth

tree -L 2
tree -L 1
  • -L N stops after N levels deep
  • great for a quick overview of a big repo before you drown in it

3 Show hidden files

tree -a
tree -a -I "node_modules"
  • -a includes dotfiles
  • -I "pattern" ignores matching names, pipe-separate for more

4 Directories only

tree -d
tree -d -L 3
  • -d hides files, showing just the folder structure
  • pairs well with -L for a map of a big project

5 Sizes and file counts

tree -h
tree -s -h
tree --du -h
  • -h shows human-readable sizes next to each file
  • --du totals size per directory instead of a flat summary
  • -s shows exact size in bytes

6 Save or tidy the output

tree -o out.txt
tree --noreport
tree -L 2 -I ".git"
  • -o writes to a file instead of the terminal
  • --noreport drops the trailing summary line
Try it now!
Run tree -L 2 -a -I ".git|node_modules" in any project.
